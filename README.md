# Vendora – متجر قطع غيار الغلايات

العميل يختار القطع → السلة → "إتمام الشراء" يفتح واتساب (01065019364) برسالة فيها كل بيانات الطلب.

## التشغيل
    npm install
    npm run dev      # تطوير
    npm run build    # بناء للنشر (مجلد dist)

## لوحة الإدارة
الرابط: `/#/admin` (أو "دخول الإدارة" أسفل الموقع).

### إعداد Firebase (مرة واحدة)
1. بيانات المشروع موجودة في ملف `.env` (انسخ `.env.example` لو بتبدأ من الأول).
2. Firebase Console → **Authentication → Sign-in method** → فعّل **Email/Password**.
3. **Authentication → Users → Add user**: أنشئ إيميل وباسورد الأدمن.
4. **Firestore Database** → أنشئ قاعدة بيانات لو مش موجودة.
5. **Firestore → Rules**: ضيف المحتوى الخاص بـ `vendora_*` من ملف `firestore.rules`
   (لا تستبدل قواعد التطبيقات التانية في نفس المشروع) وغيّر الإيميل جواه لإيميل الأدمن، ثم Publish.
6. ادخل `/#/admin` → سجّل دخول → اضغط **استيراد القطع** (مرة واحدة) → بعدها تقدر تضيف وتعدّل وتخفي وتحذف.
7. (اختياري) بعد إنشاء الأدمن عطّل إنشاء حسابات جديدة من Authentication → Settings → User actions.

الصور بتتصغّر تلقائي وبتتخزن مع بيانات القطعة، مفيش حاجة اسمها Firebase Storage هنا (مش محتاج خطة مدفوعة).

### النشر
متغيرات `VITE_FIREBASE_*` لازم تتضاف في إعدادات الاستضافة (Vercel/Netlify) لأنها بتدخل وقت البناء.

## التعديل
- `src/config.ts`: اسم المتجر، رقم الواتساب، العنوان، الأقسام.
- `src/data/products.ts`: القطع الافتراضية (بتُستورد للوحة الإدارة مرة واحدة).
